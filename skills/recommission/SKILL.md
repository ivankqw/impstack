# Recommission this machine

Refresh an existing `machine-<hostname>` skill after the machine or impstack contract changes.

1. Locate the existing machine record under the directory from `bin/skills-sync resolve-shared`.
2. Run `commission` to probe the machine into a temporary record and wizard.
3. Diff the temporary record against the existing record.
4. Run every remediation that is safe and does not require human input.
5. If a human step remains, report the generated wizard path and stop that correction.
6. Re-probe into a second temporary record after each correction.
7. Replace the existing record only with the final generated bytes.
8. Run `bin/commission check --format text`.
9. Run the proof command recorded under `proof.install-bin`.
10. Open at most one PR when the record changed and both checks pass. Include only the generated record correction that belongs in a tracked private layer.

Report `clean` when the record has no diff. Report `changed` when one proven PR contains the correction. Report `blocked` with the assertion ID and command when proof cannot finish.

Do not copy commission logic into this skill. Do not change installation state beyond a specific recorded remediation. Keep generated global files and wizards out of the portable repository.
